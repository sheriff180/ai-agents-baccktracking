
Input: The program should accept input puzzles from .txt or .csv files (supporting either format
is sufficient). Each file contains a 9x9 Sudoku grid as 9 lines, one per row; each line holds 9 values
separated by spaces (.txt) or commas (.csv), where each value is a digit 1–9, or 0 for an empty cell.

Some websites to look for Sudoku puzzles:
• https://www.websudoku.com/
• https://sudoku.com/
Output: The program must display the solved Sudoku puzzle in a clean and readable format; if
a puzzle has no solution, the program should say so. It does not have to print performance metrics
